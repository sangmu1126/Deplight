# 배포 시스템 (Deployment System) - v3

> **최신 버전**: v3 - GitHub 레포지토리: https://github.com/Softbank-mango/deplight-platform-v3

## v3의 새로운 기능

### 🎨 대시보드 개선 사항
- **모던 Glassmorphism UI**: 백드롭 블러 효과가 적용된 다크 테마
- **실시간 배포 추적**: 8단계의 진행 상황 시각화
- **강화된 서비스 카드**: 빠른 작업(Quick actions)이 가능한 상세 배포 정보
- **로컬 개발**: 개발을 위해 대시보드는 http://localhost:3000 에서 실행됨

### ⚡ 성능 최적화
- **UV 패키지 매니저**: Python 종속성 설치 시 pip보다 5-10배 빠름
- **BuildKit 캐싱**: 최적화된 Docker 레이어 캐싱
- **AI 분석 캐시**: DynamoDB 기반 캐시로 캐시 적중 시 분석 시간을 60초에서 0.5초로 단축
- **배포 소요 시간**:
  - 최초 배포 (AI 분석 포함): ~60-120초
  - 후속 배포 (캐시 적중 시): ~7-10초
  - 목표치였던 10분 대비 1,700% 속도 향상

### 🏗️ 인프라 업데이트
- **Circuit Breaker 배포**: CodeDeploy의 복잡성을 제거한 빠르고 안전한 배포 방식
- **Terraform Local 모드**: 단순화된 인프라 관리
- **동적 배포 구성**: Blue-Green 또는 Circuit Breaker 모드를 유연하게 선택 가능

## 핵심 설계 포인트 (Core Design Points)

- **GitHub → AWS 인증**: GitHub OIDC와 AWS IAM 역할(Web Identity)을 사용하여 수명이 짧은 자격 증명을 생성합니다. 워크플로우에서는 `aws-actions/configure-aws-credentials`를 사용하며, 수명이 긴 비밀 키(Long-lived secrets) 사용을 최소화합니다.
- **이미지 태그 전파**: GitHub Actions가 `<commit_sha>` 태그로 이미지를 ECR에 푸시합니다. Terraform CLI 배포 단계에서 이 값을 `-var="image_tag=<commit_sha>"`로 전달하여 ECS 작업 정의(Task Definition)를 업데이트합니다.
- **코드형 인프라 (IaC)**: Terraform 모듈은 레포지토리의 `infrastructure/` 디렉토리에 위치합니다. GitHub Actions에서 **로컬 상태(Local state) 또는 원격 백엔드(S3 상태 + DynamoDB 락킹)를 사용하는 Terraform CLI**를 실행합니다. 환경별 설정(서브넷, DB 크기 등)은 변수 파일이나 워크스페이스 디렉토리로 분리하여 유지합니다.
- **AI 분석기 연동**: Lambda "AI Code Analyzer"가 코드베이스를 스캔하여 **프레임워크, 언어, 포트, CPU/메모리 요구 사항, 종속성 패키지** 등을 유추한 뒤 다음 작업을 수행합니다:
    1. 최적화된 Dockerfile 자동 생성
    2. 즉각적인 재배포를 위해 분석 결과를 DynamoDB에 캐싱
    3. GitHub Actions 로그를 통한 배포 권장 사항 제공
- **롤백 전략 (Rollback Strategy)**:
    - Circuit Breaker 사용 시: 헬스 체크 실패 시 자동 롤백 (30초 소요)
    - 수동 롤백: GitHub Actions에서 `terraform apply -var=image_tag=<previous>`를 실행하여 이전에 정상 동작했던 태그를 재적용
- **가시성 (Observability)**: CloudWatch Logs, ECS 태스크 모니터링, ALB 헬스 체크를 통해 종합적인 모니터링을 제공합니다. 대시보드는 실시간 배포 상태와 서비스 헬스 상태를 표시합니다.

## 요약 매트릭스 (Summary Matrix)

| 계층 (Layer) | 구성 요소 (Components) | 역할 (Role) | v3 개선 사항 (Enhancements) |
| --- | --- | --- | --- |
| **UI 계층** | 대시보드 (React + FastAPI) | 배포 관리를 위한 모던 UI | Glassmorphism 디자인, 실시간 진행 상황, 로컬 개발 모드 |
| **개발자 계층** | GitHub Repo | 대시보드를 통한 코드 제출 | 조직(Organization) 및 개인 레포지토리 모두 지원 |
| **자동화 계층** | GitHub Actions | 빌드/테스트/배포 자동화 | UV 패키지 매니저, BuildKit 최적화 |
| **인프라 계층** | Terraform (Local/Remote) | ECS, ALB, Circuit Breaker 관리 | 동적 배포 모드, 단순화된 설정 |
| **AWS 실행 계층** | ECS + ALB + CloudWatch | 오토 스케일링이 적용된 서비스 실행 | 초고속 배포(7-10초)를 위한 Circuit Breaker 도입 |
| **분석 계층** | AI Code Analyzer (Lambda) | 프레임워크 감지 및 Dockerfile 생성 | 즉각적인 재배포를 위한 DynamoDB 캐시 |
